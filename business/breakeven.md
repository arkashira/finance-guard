# breakeven.md

## Unit Economics & Break-even Analysis for Finance-Guard

### Cost per Active User
- **Compute Costs**: $0.50/user/month
- **Storage Costs**: $0.10/user/month
- **Bandwidth Costs**: $0.05/user/month
- **Total Cost per Active User**: 
  - **Total**: $0.50 + $0.10 + $0.05 = **$0.65/user/month**

### Pricing Tiers
| Tier Name       | Price ($/mo) | Features                                                                                       |
|------------------|--------------|------------------------------------------------------------------------------------------------|
| Basic            | $15          | Transaction monitoring, Basic issue resolution, Email support                                  |
| Professional     | $30          | All Basic features + Advanced analytics, Priority email support, Monthly performance reports   |
| Enterprise       | $60          | All Professional features + Custom integrations, Dedicated account manager, 24/7 support     |

### Customer Acquisition Cost (CAC) Range
- **CAC Estimate**: $100 - $150 per user
  - This includes marketing expenses, sales team costs, and onboarding efforts.

### Lifetime Value (LTV) Estimate
- **Average Revenue per User (ARPU)**: 
  - Basic: $15
  - Professional: $30
  - Enterprise: $60
- **Average Customer Lifespan**: 24 months
- **LTV Calculation**:
  - Basic: $15 * 24 = **$360**
  - Professional: $30 * 24 = **$720**
  - Enterprise: $60 * 24 = **$1440**

### Break-even Users Count
- **Fixed Costs Estimate**: $10,000/month (including salaries, infrastructure, and operational costs)
- **Contribution Margin per User**:
  - Basic: $15 - $0.65 = **$14.35**
  - Professional: $30 - $0.65 = **$29.35**
  - Enterprise: $60 - $0.65 = **$59.35**
- **Break-even Users Count**:
  - Basic: $10,000 / $14.35 ≈ **698 users**
  - Professional: $10,000 / $29.35 ≈ **340 users**
  - Enterprise: $10,000 / $59.35 ≈ **169 users**

### Path to $10K MRR
To achieve $10,000 MRR, we can consider the following scenarios based on pricing tiers:

1. **Basic Tier**:
   - $15/month * 700 users = $10,500 MRR

2. **Professional Tier**:
   - $30/month * 334 users = $10,020 MRR

3. **Enterprise Tier**:
   - $60/month * 167 users = $10,020 MRR

### Summary
- To reach $10K MRR, we can target approximately:
  - 700 users on the Basic tier,
  - 334 users on the Professional tier, or
  - 167 users on the Enterprise tier.
