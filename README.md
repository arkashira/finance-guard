# 🚀 Finance-guard

**Power financial institutions with real-time fraud detection and compliance automation.**

Finance-guard is a financial security platform that empowers institutions with real-time fraud detection and compliance automation, used by financial institutions and regulatory bodies.

## Why Finance-guard?

* **Robust Security**: Detect and prevent financial fraud in real-time.
* **Compliance Automation**: Automate regulatory compliance for financial institutions.
* **Scalable**: Built to handle large volumes of financial transactions.
* **Flexible**: Integrates with various financial systems and technologies.
* **Secure**: Protects sensitive financial data with robust security measures.
* **Compliant**: Meets and exceeds regulatory requirements for financial institutions.

## Getting Started

1. Clone the repository: `git clone https://github.com/axentx/finance-guard.git`
2. Install dependencies: `poetry install`
3. Run the application: `poetry run python src/main.py`

## Deploy

1. Build the application: `poetry build`
2. Deploy to production: `poetry run python deploy.py`
